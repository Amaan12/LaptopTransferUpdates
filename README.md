# 💻 Laptop Transfer Updates

Reference and setup guide for fresh installation, system configuration, and software migration on the ROG Strix laptop.

---

## ⚡ System Tweaks & Performance

- **Remove animations** — Disable Windows transition and visual effects for maximum responsiveness.
- **Remove bloatware** — Uninstall pre-installed OEM trialware and unnecessary background services.
- **Battery health cap** — Set charging limit to **80%** (*ASUS Battery Care Mode* via MyASUS / G-Helper) to preserve long-term battery lifespan.
- **Window hover activation** — Enable "Activate a window by hovering over it with the mouse" in Windows Accessibility / Ease of Access settings.

---

## 🎨 Display & Appearance

- **Dark Mode** — Enable system-wide and app dark mode.
- **Display Scaling**:
  - **Laptop Screen**: `125%` zoom level
  - **External Monitor**: `100%` zoom level

---

## 📦 Software Installation

### 1. Ninite Multi-Installer
Batch install essential utilities and base applications via [Ninite](https://ninite.com/):
- **Browsers**: Google Chrome, Brave
- **Utilities**: WinRAR
- **Gaming**: Steam, Epic Games Launcher

### 2. Browsers & Web Apps
- **Google Chrome & Brave**
  - Install browser extensions (refer to [browser-extensions](https://github.com/Amaan12/browser-extensions) repository).
- **Web-only apps** *(use via browser instead of installing desktop clients)*:
  - ~~Spotify~~ → Use web player in browser
  - ~~Zoom~~ → Use web client in browser

### 3. Development & Creative Stack
- **Blender**
  - Transfer startup `.blend` file.
  - Transfer user preferences.
  - Reinstall / transfer custom add-ons.
- **Unity Hub**
  - Sign in and link Unity licenses and editor installations.
- **Visual Studio Code**
  - Install font: `Inconsolata for Powerline`.
  - Settings Sync / restore configs (backed up in [Amaan12PreferenceApplier](https://github.com/Amaan12/Amaan12PreferenceApplier)).

### 4. Note-Taking
- **Obsidian**
  - Open and configure personal vaults.

---

## ⚙️ Per-App Configuration

### 🎮 Steam
- Apply Steam client performance & optimization settings (disable smooth scrolling / web helper overhead).
- Configure notification settings (suppress non-essential popups / sounds).
